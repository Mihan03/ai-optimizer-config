# KHL model v2

Модель голов КХЛ за 60 минут + ОТ/буллиты, обучаемая на истории, с проверкой против рынка.

| Файл | Что это |
|---|---|
| `khl_model.py` | модель, бэктест, подбор параметров, прогноз |
| `make_synthetic.py` | синтетические данные для проверки конвейера |
| `khl_simulation_v2.xlsx` | журнал с формулами (P&L, EV, CLV, Brier, yield, калибровка) |
| `KHL_Simulation_Prompt_v2.md` | рабочий протокол v2 |
| `khl_simulation_v1.py` | старая версия (для сравнения) |

Установка: `pip install numpy scipy pandas`

## Порядок работы

```bash
python khl_model.py selfcheck                                   # аналитика = Monte Carlo, суммы = 1
python khl_model.py tune     --matches matches.csv              # подобрать затухание и усадку (~10 мин)
python khl_model.py backtest --matches matches.csv --odds odds.csv --half-life-days 180 --l2-team 8
python khl_model.py predict  --matches matches.csv --fixtures fixtures.csv --odds odds.csv \
                             --cutoff "2026-10-03 12:00" --bank 10000 --blend-w 0.3
```

`backtest` печатает главное: **лучше ли модель закрытия рынка по log loss**. Если хуже —
ставить можно только с маленьким весом модели в пуле (`--blend-w`), а лучше доработать модель.
Лучший `w` из отчёта подставляйте в `predict`.

## Форматы CSV

Даты: `29.09.2026` или `2026-09-29`. Кодировка UTF-8.

### matches.csv — сыгранные матчи (2–3 сезона + текущий)

| колонка | обяз. | пример | комментарий |
|---|---|---|---|
| match_id | да | KHL-2026-0123 | уникальный |
| season | желательно | 2026 | первый сезон в файле = обучение для бэктеста |
| stage | нет | regular / playoff | по умолчанию regular |
| date | да | 29.09.2026 | |
| home, away | да | ЦСКА, СКА | названия одинаковые во всех файлах |
| home_60, away_60 | да | 2, 2 | **счёт основного времени** |
| ot_so | да* | OT / SO / пусто | пусто = решён в основное время |
| home_final, away_final | да* | 3, 2 | итоговый официальный счёт (с решающим голом/буллитом); для матчей без ОТ можно не заполнять |
| home_en, away_en | желательно | 1, 0 | голы в пустые ворота за 60 минут |
| home_goalie, away_goalie | желательно | Фамилия И. | стартовые вратари |

\* нужны для модели ОТ/Б и рынков «с учётом ОТ».

### fixtures.csv — матчи для прогноза

`match_id, date, home, away[, stage, home_goalie, away_goalie]`. Если вратарь не подтверждён,
запустите прогноз дважды (с каждым кандидатом) — это два сценария; ставка — только если
EV положителен в обоих.

### odds.csv — коэффициенты одной БК

| колонка | пример | комментарий |
|---|---|---|
| match_id | KHL-2026-0123 | |
| bookmaker | FONBET | |
| market | 1x2 / dc / total / handicap / win | |
| period | 60 / incl_ot | правила БК! «тотал основного времени» и «тотал с ОТ» — разные рынки |
| line | 5.5 / -1.5 / 5.25 | для форы — фора **хозяев** |
| odds_1 | 2.10 | 1x2: П1 · dc: 1X · total: больше · handicap: хозяева · win: П1 |
| odds_X | 4.20 | 1x2: Х · dc: 12 · остальное пусто |
| odds_2 | 3.30 | 1x2: П2 · dc: X2 · total: меньше · handicap: гости · win: П2 |
| timestamp | 2026-10-02 12:55 | время, когда видели котировку |
| is_closing | 0 / 1 | 1 = закрытие (последний срез перед стартом) |

Минимум на матч: строка 1x2 при решении о ставке (`is_closing=0`) и та же строка перед стартом
(`is_closing=1`). Без закрытия нет CLV — главного раннего индикатора.

## Что делает модель

1. **Силы команд**: пуассоновский GLM `log λ = μ + дом + атака − оборона − вратарь + b2b`,
   веса матчей затухают со временем, атака/оборона/вратари усаживаются к среднему лиги (ridge).
2. **Концовка матча**: из счёта ±1 лидер забивает в пустые или отстающий сравнивает, из ±2 —
   лидер забивает в пустые. Параметры и масштаб λ подбираются по истории счетов —
   это исправляет занижение ничьих независимым Пуассоном и не считает пустые ворота дважды.
3. **ОТ/буллиты**: P(хозяева) = логистическая функция от разницы сил; в плей-офф сжимается к 50%.
4. **Неопределённость параметров**: 200 выборок коэффициентов из апостериорного распределения →
   диапазон вероятностей и консервативный EV (`EV_low`).
5. **Рынок**: снятие маржи (пропорционально), логарифмический пул модели и рынка с весом `w`.
6. **Отбор**: EV ≥ 3%, EV_low ≥ 0, |p − q| ≤ 5 п.п., кэф ≤ 4.0; не больше одной ставки на матч
   (наибольший EV_low); ставка = ¼ Келли, не больше 2% банка.
