# khl_simulation v2.0 — модель матчей КХЛ

Код, который считает всё, что в v1.0 вписывалось в таблицу вручную: λ команд, вероятности рынков, EV, отбор и размер ставок. Таблица `khl_simulation_v2.xlsx` собирается скриптом `scripts/build_workbook.py`.

## Что изменилось относительно v1.0

| Проблема v1.0 | Решение v2.0 |
|---|---|
| Независимый Пуассон даёт ничью за 60 минут в 13–18% случаев, рынок — около 20–23%. Недостающая вероятность ничьей уходила в П1/П2, и на фаворитах появлялся ложный «перевес» | Поправка на ничьи `draw_inflation` (θ) в матрице счетов |
| Голы в пустые ворота не учитывались, а они важны для фор −1.5 и тоталов | `empty_net_shift`: часть побед в 1 шайбу превращается в +2 |
| EV +6…+13% по каждой ставке — признак самоуверенной модели, а не перевеса | Логарифмический пулинг модели с рынком без маржи; EV только по итоговой вероятности |
| «Надёжные» ставки без фильтра EV: все 7 были в минусе даже по вероятностям самой v1 | Один фильтр для всех пулов: EV ≥ 3% и EV ≥ 0 во всех стресс-сценариях |
| Три коррелированные ставки на один матч | Не больше одной ставки на матч; пул определяется коэффициентом |
| Ставка 1000 при банке 1000, банк пула ушёл в −1200 | ¼ Келли от текущего банка, потолок 3%, банк не уходит в минус, стоп при падении ниже 50% |
| Win rate как главная метрика | Yield со стандартной ошибкой, CLV по закрытию линии, Brier/log loss против рынка по всем матчам |
| Откуда взялись λ, неизвестно | Рейтинги att/def фитятся кодом только по матчам до даты прогноза и хранятся во вкладке «Рейтинги» |
| Monte Carlo на 100 000 симуляций с шумом ~0.3 п.п. | Точный расчёт по матрице счетов |

Пересчёт 21 ставки v1 по новым правилам — во вкладке «Пересчёт v1→v2»: ни одна не проходит отбор.

## Установка

```bash
cd khl_simulation
pip install -r requirements.txt
python -m pytest -q tests
```

## Ежедневный цикл

```bash
# 1. рейтинги на дату (используются только матчи до неё)
python -m khl_model fit --results results.csv --as-of 2026-10-01 --out ratings.json

# 2. прогноз и отбор (банки пулов берутся из журнала)
python -m khl_model predict --matches matches.csv --odds odds.csv \
    --ratings ratings.json --journal journal.csv --out-dir out/
#   out/forecast.csv         — прогноз по каждому матчу (вкладка «Прогнозы»)
#   out/offers_evaluated.csv — все предложения БК с EV и причинами
#   out/picks.csv            — отобранные ставки с размером (вкладка KHL)

# 3. раз в неделю — качество
python -m khl_model evaluate --journal journal.csv

# 4. раз в месяц / после ≥300 матчей сезона — калибровка PROVISIONAL-параметров
python -m khl_model calibrate --results results.csv
```

Форматы входных файлов — в `data/` (`results_template.csv`, `matches_example.csv`, `odds_example.csv`). В `odds_example.csv` реальны только цены, которые были в журнале v1 (П1 1.55, 1X 1.16, ТМ 4.5 1.90); остальные строки иллюстративные. Для матча без рейтингов можно передать `lam_home`/`lam_away` в `matches.csv` напрямую.

Рынки: `1X2` (1/X/2), `DC` (1X/X2/12), `TOTAL` (O/U + line), `HCP` (1/2 + фора этой команде), `TEAM_TOTAL` (1O/1U/2O/2U + line) — всё за 60 минут; `ML_OT` (1/2) — победитель с ОТ и буллитами.

## Что нужно сделать до реальных ставок

1. **Собрать историю КХЛ** минимум за 2 сезона в формате `results_template.csv`: счёт за 60 минут и итоговый, плюс тип окончания REG/OT/SO. KHL.ru закрыт от автоматической выгрузки, поэтому данные нужно выгрузить вручную или через свой парсер.
2. **Запустить `calibrate`.** Параметры со статусом PROVISIONAL (θ, пустые ворота, ОТ, поправки на вратаря и back-to-back, вес модели) сейчас выставлены вручную. θ = 0.40 подобран так, чтобы P(X) совпала с рыночной по вашим кэфам.
3. **Для веса модели** нужны исторические рыночные вероятности 1X2 (колонки `q1, qx, q2` в истории). Без них вес остаётся 0.40.
4. **Первые 100–150 ставок** оценивать по CLV, а не по прибыли.

## Структура

```
khl_model/
  config.py     параметры (params.json), статусы PROVISIONAL
  ratings.py    регуляризованный Пуассон att/def, затухание, переход между сезонами
  scores.py     матрица счетов 60 мин, ничьи, пустые ворота, ОТ/Б, все рынки
  market.py     снятие маржи (power / multiplicative), пулинг модели с рынком
  betting.py    EV, стресс-тест, отбор, Келли, расчёт ставок
  forecast.py   прогноз на игровой день
  calibrate.py  walk-forward калибровка
  evaluate.py   yield, CLV, Brier, log loss, калибровочные бины
scripts/build_workbook.py   сборка khl_simulation_v2.xlsx
data/v1_bets.csv            21 ставка v1 для пересчёта
```
